Tema 1 — Pensamiento computacional y Python

Clase 1▾

El pensamiento computacional es una forma de resolver problemas de manera ordenada y lógica. Se basa en cuatro pilares:

01

Descomposición

Dividir el problema en partes más pequeñas.

02

Patrones

Identificar repeticiones y similitudes.

03

Abstracción

Quedarse con lo esencial, ignorar lo demás.

04

Algoritmos

Instrucciones paso a paso hacia la solución.

Python es el lenguaje de programación más popular del mundo. Es open source, gratuito, y funciona en Windows, Mac y Linux. Su sintaxis es tan clara que parece inglés.

primer_programa.py
# Este es un comentario — Python lo ignora
print("Hola, soy estudiante de 11° del JFK")

# Practica gratis en: replit.com o trinket.io

La función print() muestra texto en pantalla. Lo que va entre comillas es texto — Python lo llama str.

Tema 2 — Variables y tipos de datos

Clase 2▸

Una variable es un espacio en la memoria donde guardamos un dato. Tiene un nombre que elegimos y puede cambiar durante el programa.

variables.py
nombre = "Kevin" # str — texto
edad = 17 # int — entero
nota = 4.5 # float — decimal
aprobado = True # bool — lógico
materias = ["Mat","Tec"] # list — lista
TipoPythonEjemploUso
Textostr"Colombia"Nombres, mensajes
Enteroint42Edades, cantidades
Decimalfloat4.5Notas, precios
LógicoboolTrue / FalseCondiciones
Listalist[1,2,3]Colecciones

Reglas de nombres: deben empezar con letra o _, sin espacios, y no pueden ser palabras reservadas de Python como for, if, print.

Tema 3 — Operadores en Python

Clase 2▸

Los operadores son símbolos para realizar cálculos o comparaciones sobre variables y valores.
